① 页面结构（信息架构）

全局框架：底部 Tab 5 个

  • 首页（我的车） —— 车辆状态总览 + 高频快捷控制
  • 车控（控制中心） —— 全量远程控制命令，按域分组
  • 发现 / 服务 —— 保养提醒、充电地图、道路救援、社区
  • 消息 —— 告警推送、电子围栏触发、工单进度
  • 我的 —— 账号、车辆管理、数字钥匙权限、设置

③ UI 配色方案（斑马车机对齐）

深空黑 #0B0F14

全局背景，对齐斑马车机深色模式，降低夜间刺眼。

卡片深蓝 #121A24

卡片/面板底色，层级区分。

斑马青 #00D4B8

主品牌色：主按钮、选中态、在线状态。

科技蓝 #2E8CFF

插混充电、纯电续航、链接状态。

警示琥珀 #FFB020

保养提醒、围栏触发、低电量。

告警红 #FF5A5A

异常告警、紧急救援、防盗触发。

雪白 #F2F5F8

正文文字 / 浅色模式背景。

雾灰 #8A97A6

次级说明文字、禁用态。

渐变点缀

青→蓝渐变用于能量流、进度条、Logo 光效。

规范建议：圆角 16/24dp，卡片间距 12dp；主按钮高 48dp 满足拇指热区；正文 ≥ 16sp，对比度 ≥ 4.5:1；图标线性 2px 描边，与斑马 HMI 图标语言一致；支持深/浅色双主题跟随系统。

⑤ 车载互联安全要点

🔐 通信与身份安全

  • App↔T-Box 全链路 TLS 1.3 加密，指令带时间戳 + 随机数防重放。
  • 远程控制指令需二次验证：密码/生物识别（指纹、人脸）+ 短信 OTP，高危指令（解锁、启动、开后备箱）强制 step-up 认证。
  • Token 短期有效 + 刷新轮换，密钥存 Keychain（iOS）/ Keystore（Android），禁止明文日志。
  • 防逆向：代码混淆、证书绑定（SSL Pinning）、Root/越狱检测降级处理。

🔑 数字钥匙安全

  • 蓝牙钥匙基于 UWB/BLE 安全测距，防中继攻击（RSSI/ToF 距离校验）。
  • 钥匙分层权限：仅解锁 / 解锁+启动 / 临时钥匙（限定时间与次数），分享需双方实名。
  • 钥匙吊销实时生效、离线缓存黑名单；手机丢失可远程挂失。
  • 车辆侧：连续失败锁定、异常位置解锁告警推送。

📡 控车链路安全

  • 关键指令（远程启动）车端二次确认条件：P挡、车门关、油/电正常方可执行。
  • 电子围栏与位置数据本地+服务端双重校验，越界告警走独立高优通道。
  • OTA 升级签名验签 + A/B 分区回滚，升级过程禁止断电打断。
  • API 网关限流、防刷，异常指令（1分钟内高频控制）熔断并告警。

🛡️ 数据与端侧安全

  • 车端 T-Box 安全启动（Secure Boot）、HSM 硬件加密模块存储根密钥。
  • 个人数据（位置、行程、钥匙）传输与存储加密，密钥轮换机制。
  • 最小权限原则：APP 仅申请定位、蓝牙等必要权限，权限用途弹窗说明。
  • 安全审计与渗透测试常态化，漏洞赏金计划。

⑥ 合规注意事项

🇨🇳 中国法规

  • 个人信息保护法（PIPL）：位置、生物识别等敏感信息单独同意；隐私政策显著告知；支持撤回同意与注销。
  • 数据安全法：重要数据境内存储，履行数据分级分类。
  • 汽车数据安全管理若干规定：车内处理优先、默认不收集、精度范围适用、脱敏处理；重要数据出境需安全评估。
  • GB/T & 行业标准：遵循《汽车整车信息安全技术要求》（GB 44495）、车联网网络安全标准。
  • 地图与定位：使用具备甲级测绘资质的图商（高德/百度），坐标系合规（GCJ-02）。

🌍 出海 / 双端上架

  • GDPR：数据最小化、用户访问与被遗忘权、DPO 设置、跨境传输机制（SCC）。
  • iOS：位置/蓝牙权限文案按 Apple 审核要求；MFi 与 CarPlay 关联说明；隐私清单（Privacy Manifest）。
  • Android：后台定位、蓝牙扫描须运行时授权；适配厂商推送通道。
  • 功能合规：远程启动不违反驻车安全法规；电子围栏告警不构成监视他人，需车主本人授权；未成年人账号限制。
  • 营销合规：续航/油耗数据标注 CLTC 工况与测试条件。
落地建议：上线前完成等保测评与车联网安全评估；隐私政策与用户协议分层呈现，首次启动走"隐私摘要→同意"两步流程；所有位置类功能（寻车、围栏）在 UI 上提供"一键关闭定位采集"入口。
